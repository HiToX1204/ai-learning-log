## 二、细知识点

### 1. PyTorch 与 micrograd 的概念对应

| 概念 | micrograd           | PyTorch                                      |
| ---- | ------------------- | -------------------------------------------- |
| 数值 | `Value.data`      | `tensor`（标量用 `.item()` 取值）        |
| 梯度 | `Value.grad`      | `tensor.grad`                              |
| 建图 | `_prev`           | 内部 `grad_fn`                             |
| 反传 | `backward()`      | `.backward()`                              |
| 开关 | 默认记录            | `requires_grad=True`                       |
| 种子 | `self.grad = 1.0` | 内部自动设                                   |
| 累加 | `+=`              | 同样累加，**因此需要 `zero_grad()`** |

### 2. `requires_grad`

```python
x = torch.tensor(2.0, requires_grad=True)
```

- 显式告诉 PyTorch"这个张量要算梯度"
- 与 micrograd 不同（默认记录），因为 PyTorch 里大量张量（输入数据、标签）不需要梯度，关掉省显存

### 3. `.backward()` 的限制

**只能对标量（0 维张量）调用。** 对 1 维张量调用会报 `grad can be implicitly created only for scalar outputs`。

### 4. 默认精度：PyTorch 是 `float32`

```python
torch.tensor(2.0)                      # dtype=torch.float32
torch.set_default_dtype(torch.float64)  # 改成双精度，与 Python float 对齐
```

- `float32` 约 7 位有效数字 → 相对误差 `1e-7` 量级
- `float64` 约 16 位 → 误差 `1e-16` 或直接为 0

### 5. 差值三档的含义

| 差值                   | 含义                                             |
| ---------------------- | ------------------------------------------------ |
| `1e-7`               | 算法一致，精度不同（`float32` vs `float64`） |
| `1e-16`              | 都是双精度，浮点运算顺序略有差异                 |
| **`0.00e+00`** | 双精度 + 运算顺序一致 → **逐位相同**      |
| `> 1e-3`             | 有实现错误                                       |

**本次结果：四个梯度全部 `0.00e+00`**，说明手写 autograd 与 PyTorch 在算法上完全等价。

### 6. 环境与 VS Code

- `uv run` 会从"当前目录往上"找 `.venv`：仓库根有 `.venv` 时，子目录也用它
- `.vscode/settings.json`：
  - `python.defaultInterpreterPath` → 指定解释器，▶ 用它
  - `python.terminal.activateEnvironment: false` → 不执行 `Activate.ps1`
- `Activate.ps1` 只是把 venv 加进 PATH，**不参与运行代码**，禁用它不影响任何事
- 想手动"激活"：`cmd /c ".venv\Scripts\activate.bat"`（`.bat` 不受 `.ps1` 策略限制）

## 五、晚间：第一个训练闭环（W3）

### 5.1 线性回归：手推梯度与实测

数据：$x=[0,1,2,3,4]$，$y=[1,3,5,7,9]$（即 $y=2x+1$）。

$$
\mathcal{L}=\frac{1}{n}\sum_i\left(\hat y_i-y_i\right)^2,
\qquad \hat y_i = wx_i+b
$$

$$
\frac{\partial\mathcal{L}}{\partial w}=\frac{2}{n}\sum_i\left(\hat y_i-y_i\right)x_i,
\qquad
\frac{\partial\mathcal{L}}{\partial b}=\frac{2}{n}\sum_i\left(\hat y_i-y_i\right)
$$

初始 $\hat y=0$：

| 量         | 手算                          | 代码         |
| ---------- | ----------------------------- | ------------ |
| loss       | $165/5=33.0$                | `33.0` ✅  |
| $w$ 梯度 | $-2\times\overline{yx}=-28$ | `-28.0` ✅ |
| $b$ 梯度 | $-2\times\overline{y}=-10$  | `-10.0` ✅ |

**注：我一开始把 $1+9+25+49+81$ 算成 85，正确是 165——手算也要验算。**

### 5.2 200 步训练结果

| 指标      | 结果                                                                  |
| --------- | --------------------------------------------------------------------- |
| 收敛参数  | $w=2.0,\ b=1.0$（完全正确）                                         |
| loss 轨迹 | $33.0 \to 3.84 \to 0.461 \to 0.068 \to 0.02 \to \dots \to 10^{-12}$ |
| 拟合直线  | $y=2.00x+1.00$，五点全在线上                                        |

### 5.3 loss 曲线怎么读

对数纵轴下**是直线** → 指数收敛：

$$
\mathcal{L}_k\approx\mathcal{L}_0 r^k
$$

从图反推：step 10 约 $10^{-2}$，step 200 约 $10^{-12}$，跨 10 个数量级 / 190 步：

$$
r\approx10^{-10/190}\approx0.886
$$

理论值（慢方向因子 $0.94$，loss 是误差平方）：

$$
r_{\text{loss}}=0.94^2\approx0.884
$$

**实测 0.886 vs 理论 0.884** —— 与梯度对拍构成"双层闭环"。

曲线末尾（step 190+）抖动 → 接近 `float64` 精度地板，不是算法问题。

## 六、学习率：四个取值与稳定条件

### 6.1 实测（20 步）

| $\eta$ | $w$                  | $b$                  | 现象 |
| -------- | ---------------------- | ---------------------- | ---- |
| 0.001    | 0.494                  | 0.177                  | 太慢 |
| 0.01     | 1.965                  | 0.723                  | 接近 |
| 0.1      | 2.027                  | 0.922                  | 最好 |
| 1.0      | $-1.55\times10^{21}$ | $-5.45\times10^{21}$ | 发散 |

### 6.2 为什么 $\eta=1.0$ 爆炸

$$
\theta_{k+1}-\theta^\*=(I-\eta H)(\theta_k-\theta^\*),
\qquad H=\frac{2}{n}X^\top X
$$

本数据 $H=\begin{bmatrix}12&4\\4&2\end{bmatrix}$，$\lambda_{\max}\approx13.40$，$\lambda_{\min}\approx0.597$。

$$
\eta<\frac{2}{\lambda_{\max}}\approx0.149
$$

$\eta=0.1$ 收敛；$\eta=1.0$ 的增长因子 $|1-13.4|=12.4$，$12.4^{20}\approx10^{22}$，与实测同量级。

**直观版**：步长 > 到谷底的距离 → 冲过头 → 越弹越高。

### 6.3 关于"极小学习率 + 迭代到极高精度"

结论：**纯优化上成立，机器学习里不是最优。** 四个代价：

1. 步数线性膨胀（$\eta$ 小 10 倍 → 步数多 10 倍）
2. 浮点停滞（$\eta g < \text{ulp}(\theta)$）
3. 目标错位（训练 loss ≠ 泛化）
4. 过拟合（拟合噪声）

更好的做法：学习率衰减、自适应优化器（Adam）、验证集早停、凸问题用闭式解。

## 七、浮点精度（补充实验）

```python
a, b, c = 1e16, -1e16, 1.0
(a + b) + c    # 1.0
a + (b + c)    # 0.0    ← 结合律失效
1e16 + 1.0 == 1e16   # True（ulp = 2.0）
0.1 + 0.2            # 0.30000000000000004
```

| 规律               | 是否精确        |
| ------------------ | --------------- |
| 交换律 $a+b=b+a$ | ✅ 逐位精确     |
| 结合律 $(a+b)+c$ | ❌ 可能差 1 ulp |

**为什么我们的对拍是 0**：这组数（2、-3、0、-6）二进制精确可表示，每步无舍入；`b` 只参与一次加法。

**"浮点加法满足结合律"是错觉；真相是数据太干净。**

## 八、理论讨论：为什么必须有非线性

### 8.1 我的三个观点与判定

| 我的观点                   | 判定                              |
| -------------------------- | --------------------------------- |
| 无限分段线性可逼近任意函数 | ✅ 正确，且是 ReLU 网络的几何本质 |
| 必须有非线性部件           | ✅ 结论对                         |
| 理由是"要保证连续"         | ❌ 错：分段线性本身连续           |
| 手段是"嵌套 + 加减"        | ❌ 漏了"切换段"需要 max           |

**真正的原因**：仿射映射集合对复合与线性组合**封闭**。

$$
\text{仿射}\circ\text{仿射}=\text{仿射},
\qquad
\sum_k\alpha_k\cdot\text{仿射}=\text{仿射}
$$

### 8.2 泰勒展开的辨析

泰勒项是 $1,x,x^2,x^3,\dots$——**除 $x$ 外都是非线性基**。所以：

$$
\text{表达力由基函数集合决定，与"如何组合"无关}
$$

**泰勒（基固定）vs 神经网络（基可训练）** 是本质区别。

### 8.3 激活函数选择

`tanh`：有界、零中心、光滑、导数 $1-t^2$ 便宜，但**饱和 → 梯度消失**。
`ReLU`：正区间梯度恒 1，$1^{10}=1$，不衰减，但会"死亡"。

**没有最好的激活函数，只有匹配问题的。**
