### 阶段 3：补 `backward()`（20:54–21:12）

第一版：写了 `backward()`，但调用点还是 `f._backward()`，所以新方法**一次都没跑过**。

实际输出：`f.data = 8.0  a.grad = 0.0  b.grad = 0.0`

**为什么是 0（他问的）**：`_backward()` 只做"把**自己的** `grad` 分给上游"，而 `f.grad` 初始化就是 `0.0`，从没设成 $1$。

> **这是今天最重要的一个区分**：`_backward` 是"**一个节点**把梯度分给它的直接上游"，它不是反向传播本身。反向传播 = 从终点开始 + 终点梯度定为 1 + 按拓扑逆序把所有节点各调一次。

改成 `f.backward()` 后：

```

```

## 三、细知识点

### 1. `Value` 的五个字段

| 字段 | 作用 |
|---|---|
| `data` | 数值 |
| `grad` | 梯度（累加器） |
| `_prev` | 上游节点集合（构成计算图） |
| `_op` | 运算名，只为打印/调试 |
| `_backward` | **函数**：把下游传来的梯度分给上游 |

### 2. `f = a*b + a` 的梯度（路径求和）

| 变量 | 路径数 | 各路贡献 | 合计 |
|---|---|---|---|
| $a$ | 2（$a\cdot b$ 那条、$+a$ 那条） | $b=3$；$1$ | $\mathbf{4}$ |
| $b$ | 1（$a\cdot b$） | $a=2$ | $\mathbf{2}$ |

**与 M1 的"合并权重 = 各路径贡献相加"是同一个思路**：多路径 ⇒ 相加 ⇒ `+=` 必须。

### 3. `backward()` 的四步

```python
def backward(self):
    topo, visited = [], set()
    def build(v):                 # ① 后序收集
        if v not in visited:
            visited.add(v)
            for c in v._prev: build(c)
            topo.append(v)
    build(self)
    self.grad = 1.0               # ② 终点梯度定为 1
    for v in reversed(topo):      # ③ 逆序
        v._backward()             # ④ 每个节点分一次
```

严格版还要在 ② 之前**清零所有节点的 grad**，否则连调两次会累加。

### 4. `nn.Linear` 形状规则

$$\texttt{nn.Linear(in, out)}\Rightarrow\text{weight }(out,in),\;\text{bias }(out,),\;\text{输出 }(n,out)$$

- 记忆钩子：**`out` 贴在 weight 的第一维、输出的第二维**
- **bias 的个数 = weight 的行数 = 神经元数**，与 `in` 无关（今天错在这里）
