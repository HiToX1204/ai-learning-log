## 二、细知识点

### 1. `np.linspace(start, stop, num)`

- 生成 `num` 个**等间距**的数，**包含两端**
- 步长 = `(stop - start) / (num - 1)`
- 形状是 `(num,)`，一维
- 对比 `np.arange(start, stop, step)`：`arange` 给的是步长，**不包含终点**

### 2. 索引里 `None` 与 `:` 的区别

| 写法 | 结果 shape | 含义 |
|---|---|---|
| `grad` | `(5,)` | 一维 |
| `grad[None]` | `(1, 5)` | 前面插一个长度 1 的轴 |
| `grad[:, None]` | `(5, 1)` | 后面插一个 |
| `grad[None, :, None]` | `(1, 5, 1)` | 前后各插一个 |

**`None` = 插入新轴（长度 1）；`:` = 保留原轴。数值不变，只改容器形状。**

### 3. 广播规则

1. 两个形状**从右往左**逐维对齐
2. 某一维**相等**，或**其中一个为 1** → 可以运算
3. 结果每维取**较大的那个**

```
img  : (  3,   5,   3 )
grad : (  1,   5,   1 )
         ↕    ↕    ↕
结果 : (  3,   5,   3 )
```

含义：
- 行方向 `1→3`：每一行用同一个系数
- 列方向 `5=5`：每列用自己的系数
- 通道方向 `1→3`：三个通道乘同一个系数

**不插维度直接 `img * grad` 会报错**：`(3,5,3)` 与 `(5,)` 右对齐是 `3 vs 5`，对不上。

### 4. `np.clip` 与 `astype`

```python
np.clip(数组, 下限, 上限)   # 小于下限→下限，大于上限→上限
数组.astype(np.uint8)        # 转换数据类型
```

- 乘法后是 `float64`，`cv2` 不接受浮点图像
- 必须先 `clip` 再 `astype`：`200 × 1.3 = 260` 超出 `uint8` 上限，直接转会**溢出回绕**（260 变成 4）

### 5. 光照渐变模型

```python
coefficients = np.linspace(0.4, 1.3, 200)   # 每列的亮度系数
g = coefficients[None, :, None]             # (1, 200, 1)
img2 = np.clip(img * g, 0, 255).astype(np.uint8)
```

- 第 `x` 列的系数 = `0.4 + 0.9 × x / 199`
- `x=10` → 0.445 → 亮块 200 变 **89**
- `x=40` → 0.581 → 亮块 200 变 **116**
- 两者都 < 128 → 阈值 128 下整块失效

### 6. 固定阈值失效的数学本质

**阈值是绝对的，光照是相对的。** 目标灰度 `G(x) = G0 × k(x)`，其中 `k(x)` 随光照变化。

判据 `G(x) > T` 等价于 `k(x) > T / G0`：

- `T` 固定时，只要 `k(x)` 掉到 `T/G0` 以下，该区域整块被丢弃
- 本例 `T=128, G0=200` → `k` 必须 > 0.64 才能通过
- 而左半边 `k` 只有 0.44–0.58 → **全部失效**

对应到真实项目：`1676 帧只检出 1117 帧 = 66.6%`，意味着约 1/3 的帧里 `k(x)` 掉到了阈值以下。
