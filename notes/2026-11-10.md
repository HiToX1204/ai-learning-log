## 二、细知识点

### 1. `np.linspace(start, stop, num)`

- 生成 `num` 个**等间距**的数，**包含两端**
- 步长 = `(stop - start) / (num - 1)`
- 形状是 `(num,)`，一维
- 对比 `np.arange(start, stop, step)`：`arange` 给的是步长，**不包含终点**

### 2. 索引里 `None` 与 `:` 的区别

| 写法 | 结果 shape | 含义 |
|---|---|---|
| `grad` | `(5,)` | 一维 |
| `grad[None]` | `(1, 5)` | 前面插一个长度 1 的轴 |
| `grad[:, None]` | `(5, 1)` | 后面插一个 |
| `grad[None, :, None]` | `(1, 5, 1)` | 前后各插一个 |

**`None` = 插入新轴（长度 1）；`:` = 保留原轴。数值不变，只改容器形状。**

### 3. 广播规则

1. 两个形状**从右往左**逐维对齐
2. 某一维**相等**，或**其中一个为 1** → 可以运算
3. 结果每维取**较大的那个**

```
img  : (  3,   5,   3 )
grad : (  1,   5,   1 )
         ↕    ↕    ↕
结果 : (  3,   5,   3 )
```

含义：
- 行方向 `1→3`：每一行用同一个系数
- 列方向 `5=5`：每列用自己的系数
- 通道方向 `1→3`：三个通道乘同一个系数

**不插维度直接 `img * grad` 会报错**：`(3,5,3)` 与 `(5,)` 右对齐是 `3 vs 5`，对不上。

### 4. `np.clip` 与 `astype`

```python
np.clip(数组, 下限, 上限)   # 小于下限→下限，大于上限→上限
数组.astype(np.uint8)        # 转换数据类型
```

- 乘法后是 `float64`，`cv2` 不接受浮点图像
- 必须先 `clip` 再 `astype`：`200 × 1.3 = 260` 超出 `uint8` 上限，直接转会**溢出回绕**（260 变成 4）

### 5. 光照渐变模型

```python
coefficients = np.linspace(0.4, 1.3, 200)   # 每列的亮度系数
g = coefficients[None, :, None]             # (1, 200, 1)
img2 = np.clip(img * g, 0, 255).astype(np.uint8)
```

- 第 `x` 列的系数 = `0.4 + 0.9 × x / 199`
- `x=10` → 0.445 → 亮块 200 变 **89**
- `x=40` → 0.581 → 亮块 200 变 **116**
- 两者都 < 128 → 阈值 128 下整块失效

### 6. 固定阈值失效的数学本质

**阈值是绝对的，光照是相对的。** 目标灰度 `G(x) = G0 × k(x)`，其中 `k(x)` 随光照变化。

判据 `G(x) > T` 等价于 `k(x) > T / G0`：

- `T` 固定时，只要 `k(x)` 掉到 `T/G0` 以下，该区域整块被丢弃
- 本例 `T=128, G0=200` → `k` 必须 > 0.64 才能通过
- 而左半边 `k` 只有 0.44–0.58 → **全部失效**

对应到真实项目：`1676 帧只检出 1117 帧 = 66.6%`，意味着约 1/3 的帧里 `k(x)` 掉到了阈值以下。

## 四、晚间补充：Canny 边缘 + 轮廓（20:30–21:20）

### 1. 思路转折：从"绝对亮度"换到"变化量"

固定阈值判据：`gray > 128`（看**这个点有多亮**）
边缘判据：`梯度 > 阈值`（看**相邻点差多少**）

光照乘法变化 `G → G×k` 时，梯度同比缩小，但**只要仍高于阈值就还在**。所以边缘检测天然更抗光照变化。

### 2. Canny 是复合算子（四步打包）

| Canny 内部步骤 | 可单独调用的函数 |
|---|---|
| ① 高斯模糊去噪 | `cv2.GaussianBlur` |
| ② 求 x/y 梯度并合成强度 | `cv2.Sobel` |
| ③ 非极大值抑制（细化） | 无独立函数 |
| ④ 双阈值 + 滞后连接 | `cv2.threshold` 两次 |

```python
cv2.Canny(图, 低阈值, 高阈值)     # 常用比例 1:2 ~ 1:3
```

- 两个阈值是**梯度**门槛，不是灰度
- `梯度 > 高` → 强边缘直接留；`低 < 梯度 ≤ 高` → 只有连着强边缘才留；`≤ 低` → 丢

**手写近似**（理解用）：
```python
blur = cv2.GaussianBlur(gray2, (5,5), 1.5)
gx   = cv2.Sobel(blur, cv2.CV_64F, 1, 0, ksize=3)
gy   = cv2.Sobel(blur, cv2.CV_64F, 0, 1, ksize=3)
mag  = np.sqrt(gx**2 + gy**2)
```

### 3. 实验结果对比

| 方法 | 加渐变前 | 加渐变后 |
|---|---|---|
| 固定阈值 128 | 1922 | **0** |
| Canny 边缘像素 | 360 | **360** |

360 = 3 × 120，120 ≈ 矩形周长（`4×31-4`）。

### 4. `findContours` 与轮廓属性

```python
contours, _ = cv2.findContours(edges2, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
```

| 函数 | 返回 | 说明 |
|---|---|---|
| `cv2.findContours` | 轮廓列表 + 层级 | `RETR_EXTERNAL` 只要最外层 |
| `cv2.boundingRect(c)` | `(x, y, w, h)` | 最小**正**外接矩形，`x,y`=左上角，含两端（+1） |
| `cv2.minAreaRect(c)` | `((cx,cy),(w,h),angle)` | 最小**旋转**矩形（项目里判斜置装甲板用它） |
| `cv2.contourArea(c)` | 浮点面积 | 多边形面积（格林公式），不是数像素 |

### 5. 本次实测数据

| 轮廓 | 位置 | boundingRect | 面积 | 宽高比 |
|---|---|---|---|---|
| 左 | (9,10) | 33×31 | 958.0 | 1.06 |
| 中 | (70,10) | 31×31 | 900.0 | 1.00 |
| 右 | (130,9) | 32×32 | 932.0 | 1.00 |

**为什么不是整齐的 31×31、961**：边缘线落在过渡带的内侧或外侧取决于梯度最大点，Canny 的非极大值抑制会把线"挪"到局部最强处，所以普遍差 1–2 像素。**这是常态，不是 bug。**

### 6. 筛选必须用区间，不能用等号

错误写法：`if area == 961`（永远不成立）
正确写法：

```python
if 800 < area < 1100 and 0.9 < w / h < 1.1:
    保留
```

真实场景里假轮廓远多于真目标（噪点、纹理、反光），筛选靠的是**相对区间 + 多个几何条件组合**。

### 7. 排序与列表推导式

```python
boxes = [cv2.boundingRect(c) for c in contours]   # 列表推导式
boxes.sort(key=lambda b: b[0])                    # 按 x 排序
for x, y, w, h in boxes:                          # 循环时解包
```

`findContours` 的返回顺序**不保证按位置**，工程上必须自己排序（例如配对左右装甲板）。

### 8. 复合算子 vs 基础算子

- **复合**：`Canny`、`findContours`、`HoughLines`、`adaptiveThreshold` → 一行出结果，但黑箱，出问题难定位
- **基础**：`GaussianBlur`、`Sobel`、`threshold`、`morphologyEx`、`bitwise_and` → 一个只干一件事，可组合、可逐层检查

**新手爱用复合算子，工程师用基础算子拼。**
