## 二、细知识点

### 1. DataFrame 与 Series

| 对象 | 维度 | 说明 |
|---|---|---|
| `DataFrame` | 二维 | 带列名的表，每列可不同类型 |
| `Series` | 一维 | 带索引的一列，类似"加了标签的数组" |

```python
df["col"]        # 取一列 → Series
df[["col"]]      # 取一列 → 仍是 DataFrame（双括号）
```

**单方括号 vs 双方括号**是最常见的坑：`df["a"]` 得到 Series（一维），`df[["a"]]` 得到 DataFrame（二维）。

### 2. 常用属性与方法

| 写法 | 返回 | 有无括号 |
|---|---|---|
| `df.shape` | `(行, 列)` | 属性，无括号 |
| `df.columns` | 列名索引 | 属性 |
| `df.index` | 行索引 | 属性 |
| `df.dtypes` | 每列类型（Series） | 属性，无括号，复数 |
| `df["c"].dtype` | 单列类型 | 属性，单数 |
| `df.head()` | 前 5 行 | 方法 |
| `df.describe()` | 数值列统计摘要 | 方法 |

### 3. `object` / `str` / `dtype: object` 三个容易混的东西

- **`object`**：pandas 的兜底类型，装任意 Python 对象（旧版里字符串列就是它）
- **`str`**：pandas 3.x 新增的字符串专用类型，更省内存
- **`dtype: object`（打印在 dtypes 结果下方）**：这是 **dtypes 这个 Series 自身**的类型，**不是**某一列的类型

想确认单列类型：

```python
df["lighting"].dtype
type(df["lighting"].iloc[0])
```

### 4. 布尔筛选

```python
df[df["detected"]]                        # 单条件
df[(df["brightness"] > 100) & df["detected"]]   # 多条件用 & ，每个条件加括号
```

- **必须用 `&` / `|`，不能用 `and` / `or`**（同 NumPy）
- 每个条件要加括号，否则优先级出错

### 5. groupby：分组统计

```python
df.groupby("lighting")["brightness"].mean()      # 每组均值
df.groupby("lighting")["detected"].mean()        # 每组"比例"（布尔平均）
df.groupby("lighting").agg({"brightness": "mean", "detected": "mean"})   # 一次算多列
```

- 结果索引是**组名**
- 布尔列求平均 = 检出率（True 当 1）
- **意义**：把"1676 帧只检出 1117 帧"这类总体指标，拆成"白天 95% / 夜间 40%"，问题立刻定位

### 6. `idxmin` / `idxmax` / `argmin` 的区别

| 写法 | 返回 |
|---|---|
| `series.idxmin()` | 最小值的**标签**（组名、行索引） |
| `series.argmin()` | 最小值的**位置**（第几个） |
| `np.argmax(arr)` | 扁平位置（NumPy） |

要找"哪一组最差"用 `idxmin()`，因为它直接给你组名。

### 7. NaN（缺失值）

```python
np.nan == np.nan          # False     ← 唯一不等于自己的值
np.isnan(x) / pd.isna(x)  # 判断缺失
pd.Series([1, np.nan, 3]).dtype   # float64  ← 整数列遇 NaN 会升级
pd.Series([1, np.nan, 3]).sum()   # 4.0      ← pandas 默认跳过 NaN
np.array([1, np.nan, 3]).sum()    # nan      ← NumPy 会污染结果
```

- 判断缺失**不能用 `==`**，要用 `isna` / `isnan`
- pandas 的 `mean` 分母是**有效值个数**（和 `arr[mask].mean()` 同理）

### 8. CSV 读写

```python
df.to_csv("x.csv", index=False)      # index=False：不把行号写成一列
df2 = pd.read_csv("x.csv")
```

- 不写 `index=False` → CSV 多一列无名列 → 读回来变成 `Unnamed: 0`
- **什么时候保留 index**：index 是"有意义的信息"（时间戳、ID、分组键）时保留；只是行号时丢掉
- 类型在往返时可能变化（尤其旧版 pandas / 混合类型列），需要时用 `dtype={...}` 显式指定
