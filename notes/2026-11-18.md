## 二、细知识点

### 1. 常量混算：`isinstance` 包装

```python
def __add__(self, other):
    other = other if isinstance(other, Value) else Value(other)
```

- `isinstance(对象, 类型)` 是内置函数，判断类型（认子类，优于 `type(x) == T`）
- `a - 1`：`other` 是 `int` → 包装成 `Value(1.0)`
- `a - b`：`other` 已是 `Value` → **原样不动**（重复包装会多一层节点，图就乱了）

### 2. 反向运算 `__radd__` / `__rmul__`

```python
__radd__ = __add__     # 1 + a  →  a + 1
__rmul__ = __mul__     # 2 * a  →  a * 2
```

- 运算符查表顺序：先 `type(a).__add__`，返回 `NotImplemented` 再 `type(b).__radd__`
- **是类级别赋值**（缩进 4 空格，和 `def` 对齐），不是方法体

### 3. 减法用组合，不写新反传

```
a - b = a + (-b) = a + (b × -1)
```

```python
def __neg__(self):     return self * -1
def __sub__(self, other):  return self + (-other)
def __rsub__(self, other): return (-self) + other
```

**好处**：只写"组合"，不写反传规则，减少出错面。代价：多建几个节点（可忽略）。

### 4. `__pow__`

```python
def __pow__(self, other):
    assert isinstance(other, (int, float)), "只支持 int/float 次方"
    out = Value(self.data ** other, (self,), f'**{other}')
    def _backward():
        self.grad += other * (self.data ** (other - 1)) * out.grad
    out._backward = _backward
    return out
```

- `(self,)` 是**单元素元组**（逗号必须有），`(self)` 只是括号
- 只有 `self.grad`，因为指数是普通数字，不是节点
- 局部导数 = `n·x^(n-1)`

### 5. `tanh`

```python
def tanh(self):
    x = self.data
    t = (math.exp(2*x) - 1) / (math.exp(2*x) + 1)
    out = Value(t, (self,), 'tanh')
    def _backward():
        self.grad += (1 - t**2) * out.grad
    out._backward = _backward
    return out
```

- `d(tanh x)/dx = 1 - tanh²x`（用激活值算导数，省一次 exp）
- 需要文件顶部 `import math`

### 6. `out.grad` 何时有值

- 每个 `Value` 在 `__init__` 里 `grad = 0.0`，所以**一定有定义**
- 调用 `out._backward()` 时，`out.grad` 已被下游（或 `backward()` 的种子 `1.0`）填好
- **顺序错了读到的是初始值 0**，不报错 → 因此顺序错难查

### 7. 神经元的数学结构

```
o = tanh( w1·x1 + w2·x2 + b )
```

- 前向：加权求和 + 偏置，再过激活
- 反向（链式）：`n.grad = (1-o²)·o.grad` → 分给各 `w`、`x`、`b`
- 本例实测：`b.grad=0.5`、`w1.grad=1.0`、`x1.grad=-1.5`、`w2.grad=0`（因为 `x2=0`）

## 三、今天的坑 / 值得记的点

1. **`__neg__` 不能写成 `-self.data`**：必须走 `self * -1`，否则新节点没连上计算图，梯度断了。
2. **`(self,)` 少了逗号就不是元组**：`(self)` 是表达式，`_prev` 会变成一个 Value 而不是集合元素。
3. **`__radd__ = __add__` 的缩进**：写在类体（4 空格），不是方法内部。
4. **`isinstance` 优于 `type()==`**：以后写 `class Neuron(Value)` 才不会漏。
5. **`w2.grad = 0` 不是 bug**：`x2 = 0`，局部导数是 `x2`，乘出来就是 0。**梯度为 0 说明"这个参数这次没影响"，不代表代码错。**
