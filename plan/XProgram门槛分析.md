## 四、怎么读这份数据

1. **门槛比想象中低**：不是"要会 CUDA、要发过论文"，而是"能写 Python + 懂 ML/DL 基本概念 + 在一个方向上能对话 + 自驱"。
2. **PyTorch 显式提及只有 19%/34%**，但它是 AI 学域的事实标准。写"机器学习基础"的课题，隐含就用 PyTorch。**不能因为它没被点名就跳过。**
3. **数学只占 24.5%**，同样是"隐性要求"——写"理解原理"的课题，背后就是线代+概率。
4. **"机器人/ROS/控制"占 42.7%**，是因为 220 项里混入了大量机器人方向课题；如果只打 AI 学域（61 项），机器人降到 41%，而 LLM 升到 37.7%。
5. **"自驱/主动沟通"占 36%**，这一项是唯一无法用"学会某个技术"替代的，只能靠**产出物**（仓库、复现报告）证明。

## 五、给 2027 年 2–3 月的目标清单

时间：现在（11 月中）到 2027 年 2 月底，约 **15 周**；按每周 8–10 小时计，约 **120–150 小时**。

| # | 能力 | 验收标准（能独立做到） | 预计周次 |
|---|---|---|---|
| 1 | Python 工程化 | 写函数/模块、用 git 分支、能读 200 行别人的代码 | 1–2 |
| 2 | NumPy / pandas | 向量化、掩码、广播、表格清洗与分组统计 | 2–4 |
| 3 | ML 概念 | 训练/验证划分、过拟合现象及对策、混淆矩阵与 P/R/F1 | 5–6 |
| 4 | 手写算法 | 纯 NumPy 写线性回归 + 逻辑回归（含梯度下降） | 6–7 |
| 5 | PyTorch | 空白文件写出训练循环，解释 `backward()` 在算什么 | 8–9 |
| 6 | 一个方向纵深（CV 或 LLM 二选一） | CV：CNN 训练+调参；LLM：微调或推理优化跑通一个最小例子 | 10–12 |
| 7 | 读论文/复现 | 读懂一篇论文的 method，做出最小可跑版本 + 写差异报告 | 13–14 |
| 8 | 自驱证据 | GitHub 上 3 个仓库：每个含 README、结果数字、一处"我改了什么" | 持续 |

**可放弃项（现在不值得投入）**：CUDA / 分布式训练 / ROS 硬件调试 / 芯片设计。它们只覆盖少数高门槛课题，且大一投入产出比极低。

## 六、结论

**在 2027 年 2–3 月达到"9 成 AI 强相关课题的显式门槛"，是可行的**，前提是：

- 把 15 周里至少 60% 的时间给第 1–6 项（工程 + ML/DL 底座）
- 第 7–8 项同步推进（每两周一个小仓库），否则"自驱"这一项无法证明
- 不追高门槛支线（CUDA/ROS/理论证明）
