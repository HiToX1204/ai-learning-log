# 第一层：小白版

## 用一个例子贯穿：学"猜房价"

你手上有一本册子（**数据**）：面积 50 平卖 300 万，80 平卖 450 万……

你一开始什么都不懂，就瞎猜一个规则：

$$
\text{价格} = w \times \text{面积} + b
$$

先设 \(w=0, b=0\)，那所有房子你都猜"0 万"。**错得离谱。**

**错多少要量化**：把每个猜测和真实值的差平方，再求平均。这就是 **loss**——一个数，代表"你有多离谱"。

**接下来做一件很自然的事**：看看"如果我把 \(w\) 调大一点，分数会变好还是变坏？"

那个敏感度就是**梯度**。

发现"调大 \(w\) 会让分变低"，就把 \(w\) 调大一点；再算一次、再调一次……

**这就是训练。**

## 对照我们真跑过的东西

| 生活里的说法            | 我们的代码                                            |
| ----------------------- | ----------------------------------------------------- |
| 册子上的房子和价格      | `x`, `y`                                          |
| 你猜的规则              | `w * x + b`                                         |
| 猜得有多离谱            | `((pred - y) ** 2).mean()`                          |
| 错多少分                | `loss = 33.0`                                       |
| "调大 \(w\) 会好一点吗" | `w.grad = -28.0`                                    |
| 调多少                  | `w -= 0.1 * w.grad`                                 |
| 调到一分不差            | loss \(33 \to 10^{-12}\)，\(w,b\) 收敛到 \(2.0, 1.0\) |

## 那"神经网络"是什么

上面的规则太死板——价格只能随面积**线性**变化。真实世界不是这样。

**神经网络 = 把简单规则叠很多层，每层之间"弯一下"。**

一个神经元只干两件事：

1. **加权求和**：把输入按重要性加起来
2. **弯一下**：过一个非线性函数（`tanh`）

$$
\text{输出} = \tanh(w_1x_1 + w_2x_2 + b)
$$

**为什么必须"弯"**：只有加减乘的话，叠一百层还是直线，白叠。

## 那"反向传播"是什么

一层还能手推。叠十层后，你根本不知道"最后错这么多，该怪最前面哪个参数"。

**反向传播 = 从最后的错误出发，一层层往前追问"你这里贡献了多少"。**

我们手算过：`o = 0.7071`，`b.grad = 0.5`、`w1.grad = 1.0`、`x1.grad = -1.5`——**每个数都在回答"你这里多 1，最后会多/少多少"**。

# 第二层：专业版

## 形式化框架

训练是求解：

$$
\theta^\* = \arg\min_\theta\ \mathcal{L}(\theta),
\qquad
\mathcal{L}(\theta) = \frac{1}{n}\sum_{i=1}^{n}\ell\left(f_\theta(x_i), y_i\right)
$$

- 线性模型：\(f_\theta(x) = w^\top x + b\)
- 单神经元：\(f_\theta(x) = \sigma(w^\top x + b)\)
- 多层：\(f_\theta = \sigma_L \circ \cdots \circ \sigma_1\)

## 核心机制：反向模式自动微分

**前向传播**构造计算图（DAG），每个节点是一次初等运算。

**反向传播**是 reverse-mode AD 的一次反向遍历：

$$
\frac{\partial \mathcal{L}}{\partial v}
= \sum_{u \in \mathrm{children}(v)}
\frac{\partial \mathcal{L}}{\partial u}\cdot\frac{\partial u}{\partial v}
$$

关键性质：

| 性质                    | 说明                                           |
| ----------------------- | ---------------------------------------------- |
| 代价 \(O(\text{前向})\) | 与参数个数无关——这是它取代数值微分的根本原因 |
| 需保留中间量            | 显存随图规模增长                               |
| 要求可微                | 离散/不可导需 STE、松弛等技巧                  |
| 顺序由拓扑序决定        | 必须等下游梯度到齐才能往上传                   |

实现了这些，`loss.backward()` 就和你手写的 60 行等价——**实测四个梯度在双精度下逐位相同**。

## 优化

$$
\theta \leftarrow \theta - \eta\nabla_\theta\mathcal{L}
$$

对二次型损失，误差按 \((I-\eta H)^k\) 衰减，稳定条件：

$$
0 < \eta < \frac{2}{\lambda_{\max}(H)}
$$

实测吻合：\(H\) 的 \(\lambda_{\max}\approx13.4\)，故 \(\eta<0.149\)；\(\eta=0.1\) 收敛、\(\eta=1.0\) 发散（\(12.4^{20}\approx10^{22}\)）。

## 适用边界

| 成立条件            | 边界情况                                            |
| ------------------- | --------------------------------------------------- |
| 损失可微            | 离散决策/采样/量化 → STE、重参数化                 |
| 图能进内存          | 长序列 → 梯度检查点                                |
| 凸损失              | 神经网络非凸 → 局部极小/鞍点，靠初始化与随机性缓解 |
| 训练分布 = 测试分布 | 分布偏移下 loss 与泛化脱钩                          |

## 常见误解

| 误解                | 纠正                                     |
| ------------------- | ---------------------------------------- |
| 反向传播 = 学习算法 | 它只算梯度；学习由优化器完成             |
| 梯度是"正确答案"    | 只是一阶局部方向，不是全局最优方向       |
| loss 越低模型越好   | 训练 loss 是优化目标，泛化是另一件事     |
| 神经元模拟大脑      | 只是"加权和 + 非线性"                    |
| 必须手写梯度        | 框架自动微分；手写仅用于自定义算子或性能 |
| 学习率越小越精确    | 小 \(\eta\) 更稳但更慢，低于 ulp 会停滞  |

# 一、术语对应表

| 小白说法       | 专业术语                                    | 代码                     |
| -------------- | ------------------------------------------- | ------------------------ |
| 册子上的例子   | 训练集 \(\{x_i,y_i\}\)                      | `X`, `Y`             |
| 猜的规则       | 参数化模型 \(f_\theta\)                     | `w*x+b`                |
| 参数           | parameters                                  | `w`, `b`             |
| 调多少         | 超参数 learning rate                        | `lr`                   |
| 错多少分       | 损失函数                                    | `((pred-y)**2).mean()` |
| 敏感度         | 梯度 \(\partial\mathcal{L}/\partial\theta\) | `w.grad`               |
| 记录"谁从哪来" | 计算图 / DAG                                | `_prev` / `grad_fn`  |
| 从结果往前追问 | 反向模式自动微分                            | `backward()`           |
| 每层干的活     | 前向传播 + 非线性激活                       | `tanh`                 |
| 反复调整       | 梯度下降                                    | 训练循环                 |
| 调到不动       | 收敛                                        | `loss → 0`            |
| 调参数的机制   | 优化器（SGD/Adam）                          | 手动 `w -= lr*grad`    |

# 二、最容易理解错的地方（都是实际踩过的）

1. **平均值不是"整表的平均"**：`arr[mask].mean()` 的分母是**选中个数**。
2. **梯度必须累加**：`+=` 而非 `=`；否则多路径时丢一份贡献。这也是 `zero_grad()` 存在的原因。
3. **顺序错了不报错**：去掉 `reversed(topo)` → 结果是 `0.0 0.0 1.0`，无异常，只有错误答案。
4. **`1e-7` 不是 bug**：`float32` vs `float64`，判断对错前先统一精度。
5. **loss 是训练目标，不是模型好坏**：真实任务里 loss→0 往往意味过拟合。
6. **学习率是步长，不是精度旋钮**：太小是"慢"，不是"准"。
